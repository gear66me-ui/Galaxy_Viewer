🔭 Aladin Pixel Scale Calibration Lab

This experiment measures Aladin's actual screen-to-sky mapping at selected fields of view. It records the view's pixel dimensions, Aladin's reported FOV, and the angular separation of the two horizontal screen-edge pixels measured through Aladin's own coordinate transform. It then compares that measured angle with the custom 46.5-billion-light-year reference model.

Grid is enabled by default; coordinate frame is ICRSd (decimal-degree ICRS). The initial view is 12°. Aladin's own angular-distance function is used for the full-width measurement and its pixel-to-world transform is sampled at the center and edges.

How to interpret this test

Pixels per degree = view width in pixels ÷ measured angular width across the view. Degrees per pixel is its reciprocal. The measured angular width comes from Aladin's pixel-to-world transform and angular-distance calculation, not merely from multiplying the requested FOV by a pixel fraction.

Custom sine reference: S(θ) = 46.5 × sin(θ/2), with θ in radians, output in billion light-years. Linear comparison: 46.5 × θ/180. These are two calibration hypotheses for comparison, not validated cosmological distance laws. The pixel measurement tests Aladin's angular mapping; it cannot by itself prove which cosmic distance model is physically correct.
