Linear reference hypothesis

Your proposed screen-width scale: if 180° is assigned 46.5 billion light-years, the proportional reference is — across the current FOV. This is a deliberately linear calibration hypothesis to compare against the celestial grid—not a standard cosmological distance conversion. The 46.5 billion light-year value is the approximate present-day radius of the observable universe, while 180° is an angular diameter.

Calibration notes

For a small angle θ in radians, transverse span ≈ distance × θ. The tangent-plane width is 2D tan(θ/2); it becomes unsuitable near all-sky fields. The physical span shown here uses your entered distance as a reference assumption, not a distance inferred from zoom.
