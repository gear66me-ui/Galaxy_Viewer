How registration works

The page matches a provider’s catalog entry to its mirror mapping, then builds an Aladin image layer with celestial reference coordinates, pixel reference point, image dimensions, pixel scale, and rotation. If an entry contains complete decoded AVM/WCS fields, those are preferred. Otherwise the page uses the provider catalog’s RA/Dec, FOV and orientation to synthesize a center-based TAN WCS; that fallback is explicitly labeled approximate and is useful for visual inspection, not proof of precise astrometric registration.

For a scientifically conclusive registration test, select images with full AVM/WCS metadata. The slider changes the actual Aladin overlay layer opacity; it does not fade a separate HTML image.
