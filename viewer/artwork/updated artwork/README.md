# Updated constellation artwork — review draft

These two 256×256 SVGs are isolated design proposals. Existing artwork and all runtime artwork pointers are intentionally unchanged.

- `CENTAURUS.SVG`: electric-blue constellation strokes, pale blue-white stars, warm emphasis on the brightest guide stars.
- `LEO.SVG`: same icon geometry and visual system, with a subtle violet background accent.

The International Astronomical Union formally defines the 88 constellations and their sky boundaries; it does not prescribe one universally official stick-figure drawing for every constellation. These are stylized icon proposals informed by familiar constellation line figures, not a claim that every segment is an IAU-mandated connection. Before rollout, compare the plotted stars/segments against the project's audited Hipparcos/IAU line data.

Folder is for review only. No production artwork pointers, route/navigation modules, or viewer behavior are changed.
