Calculation details

For angle θ in degrees and cosmic radius R = 46.5 billion light-years, the model chord is L = 2 × R × sin(θ × π / 360). The angle is measured from the ruler endpoints using Aladin's pixel-to-sky conversion when available. If that API method is unavailable, the display explicitly marks its FOV-based estimate as approximate. At 180°, the maximum chord is 93 billion light-years.
