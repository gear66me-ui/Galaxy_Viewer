How the estimates work

For narrow fields, projected transverse span ≈ distance × angle in radians. For a tangent-plane projection, the width is 2 × distance × tan(FOV/2), but this diverges near 180° and should not be used for all-sky views. The entered galaxy size and distance are reference assumptions you can change. FOV is angular coverage; zooming does not physically move the galaxy.
