How to compare

The coordinate grid is enabled initially and uses the ICRS frame. The ruler overlay is a screen-fixed reference, not a replacement for the celestial coordinate grid. The yellow ruler is fixed at 300 of 1000 SVG units (30% of viewer width). Its live angular span is estimated from the current horizontal FOV and its displayed model span uses 46.5 × sin(angle/2) billion light-years, so a 180° span equals 46.5 billion light-years (half the 93-billion-light-year observable-universe diameter). This is a geometric comparison model, not a cosmological distance law. At 180°, this model reports 46.5 billion light-years. At very wide FOVs the sky projection is nonlinear, so use narrow/mid FOVs for the cleanest pixel-to-angle check.
